1. 1. What is the difference between invoking and creating a function?

    Creating a function defines its logic and placeholders (parameters). Invoking a function means actually executing or running that function with real values (arguments).

  2. 2. Explain the syntax regarding semicolons and code blocks.

    Semicolons are used to terminate individual statements. Code blocks are grouped together inside curly braces {} to define the body of functions, loops, or conditionals.

  3. 3. What happens when we try to store values from a function when it doesn't return any?

    The variable holding the result will be assigned the value of undefined because no value was sent back using the return statement.

  4. 4. How do we separate parameters from each other when creating a function?

    Parameters are separated from each other using a comma (,) inside the parentheses of the function definition.

  5. 5. Explain how parameter names are related during the invocation and creation of a function.

    During creation, parameter names act as local variables. During invocation, the arguments passed are mapped to these parameters based on their exact position and order.

  6. 6. Explain why a parameter is undefined when a function call is missing a parameter.

    JavaScript automatically initializes any missing arguments to undefined because no specific value was provided for that placeholder during the function call.

  7. 7. Explain what happens when we use recursive functions.

    A recursive function will repeatedly call itself until it reaches a defined base case (stopping point). If there is no base case, it creates an infinite loop and crashes.
